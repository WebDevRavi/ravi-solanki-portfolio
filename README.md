## 🌌 Overview

**Blue 3D** is an art-directed, immersive portfolio blending retro pixel-art world exploration with modern creative engineering, game development, 3D visualization, and AI/ML experiments.

### Key Highlights
- **Interactive Pixel World**: Parallax starfield, animated clouds, luminous full moon, and connected spatial nodes.
- **Ravi's Workspace Studio**: Integrated pixel-art studio workstation with real-time audio ambient hum and interactive equipment.
- **Game Vault**: Interactive games showcase (Vortex Glide, Type Rush, Color Trap, Math Dash).
- **Creative & 3D Lab**: Curated portfolio of 3D renders, video editing, social media direction, and software engineering.
- **Soundscape Engine**: Web Audio synthesis for retro clicks, teleports, and atmospheric ambiance.
- **Full Responsive Design**: Fluid mobile drawer navigation, keyboard traversal, and desktop interactive viewport.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ installed
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/WebDevRavi/ravi-solanki-portfolio.git

# Navigate to the project directory
cd ravi-solanki-portfolio

# Install dependencies
npm install
```

### Development Server

Run the development server locally:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the interactive world.

### Production Build

Build and test optimized production bundles:

```bash
npm run build
npm run start
```
